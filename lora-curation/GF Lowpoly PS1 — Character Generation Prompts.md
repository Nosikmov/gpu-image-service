# GF Lowpoly PS1 — Character Generation Prompts

## Общий стиль

Каждый персонаж должен выглядеть как отдельный low-poly 3D game asset из условной PS1-era RPG: намеренно простая геометрия, крупные плоские полигоны, жёсткие грани, минимальное количество деталей, простые материалы, приглушённая палитра, отсутствие современного PBR-вида.

Общая композиция для всех персонажей:
- full body
- centered
- front-facing
- orthographic camera
- T-pose
- neutral light gray background
- no floor
- no environment
- no props
- consistent character scale
